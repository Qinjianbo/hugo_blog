# 动手之前，先过安全护栏

前五篇手越练越多：浏览器里查，桌面上按，手机上记，三只手还能连起来办事。手多了，错的代价也大了：前面一篇里一个字抄错，手机上看到的就是错的；再往前一步，一条消息发错了、一个文件删错了，就不是重练一次能解决的了。

所以这一篇不教新手，只收规矩。**把前五篇散在各处的规矩收成一张检查清单，每次动手之前过一遍，通不过就不动手。** 清单很短：两条红线、动手前六问、动手时三条、收尾四件事。

先说一句贯穿全系列的话，也是这一篇的前提：**只在备用机或小号上练。** 护栏再严，也别拿主力机、主账号练手。练手的东西，错了能重来；正式的东西，错了要负责。

## 一、两条红线

红线是不用判断的：碰到就停，停下来问你。

- **不可逆的事，必须你点头。** 发消息、付款、提交表单、删东西、改设置、发布文章，这些事一旦做了就收不回来。Agent 可以把材料准备好、把要发的内容列出来，但按下发送键、确认付款键的那一下，必须是你。不要写“顺手帮你办了”，只写“停下来等你确认”。
- **秘密信息，绝不外发，也不进记录。** 密码、验证码、密钥、证件和银行卡信息、别人的隐私，这些东西不写进交接单，不贴进对话里让 Agent 转发，也不为了“方便”存进一个能对外发的文件里。发出去之前先问一句：这条信息一旦发出去了，还收得回来吗？收不回来，就不发。

这两条还有一个共同点：**不要靠 Agent 自己判断。** “这笔钱不大，应该没事”“这条消息看着没问题”——这种判断一旦交给 Agent，出事只是早晚。红线的好处就是不用判断，碰到就停。

## 二、动手之前，先过六问

动手前花一分钟，把这六个问题过一遍。任何一个答不上来，先把那个问题解决了再动手。

1. 是在备用机或小号上练吗？不是就先换，正式的账号和主力机不动手。
2. 这一步会对外产生效果吗？发消息、付款、提交、删除、发布，只要沾上一件，就先停下来，等你点头再往下走。
3. 权限开齐了吗？跑 `agent-desktop status` 看 `data.permissions` 下面每一项的 `state`，是 `denied` 的先处理掉。JSON 挤成一坨不好读的话，在命令后面接上 `| python3 -m json.tool`，macOS 自带 python3，不用另装。
4. 快照是最新的吗？切了应用，先跑一次新快照，再动手。编号只在当次快照里有效，旧编号全作废。
5. 交接单对过了吗？跨应用的活，动手之前看的是交接单，不是凭记忆。上一手的原话没写进交接单，就别往下传。
6. 失败了停得下来吗？动手之前先知道怎么停：浏览器会话能关，手机能断开。不知道怎么停的活，别开始。

## 三、动手的时候，三条规矩

清单过完了，动手的时候还有三条，条条都是前几篇练过的老话，落到这里是同一套。

1. 一次只动一步，动完再看。看→动→再看，循环还是那一套，别贪多一次动两步，两步一起错的时候，你不知道是哪一步错的。
2. 卡住了停下来等人。验证码、权限弹窗、看不懂的确认框，都是站方特意留给人做的坎。第二篇练搜索的时候，百度弹了图形验证码，正确的办法就是切到看得见的窗口里自己做完，再让机器接着干。验证码本来就该人来过，绕过去既难也不合适。
3. 范围变了，重审一遍。做到一半发现任务变了：本来只改文字，现在要顺手改链接；本来只在本地看，现在要发出去。范围一变，动手前的六问就作废了，停下来重过一遍，再决定要不要继续。

## 四、动手之后，收尾四件事

做完不要直接说“搞定了”，先收尾，再验一遍。

1. 对一遍结果和交接单。改的是不是约定的那一份，有没有多改、改错；手机上看到的和交接单上的原话是不是一字不差。对不上就先停下来，再核对、再补救，不要接着往下做。
2. 断开手机。跑完 `agent-android disconnect` 断开连接，练完关掉 USB 调试。
3. 关掉浏览器会话。不要让一台能替你点手机、又连着浏览器的电脑，一直处于“随时能接着干”的状态。
4. 失败就写到失败那一步为止。中间一步没办成，交接单写到失败的那一步就停。下次从失败的那一步接着走，而不是从头重跑，更不是硬着头皮往下走。

## 五、护栏是底气，不是束缚

有人会觉得，规矩这么多，还怎么放手让 Agent 干活。反过来想才对：**正因为有护栏，你才敢放手。** 没有护栏的时候，每一步你都得盯着，生怕它多干了一件；有了护栏，红线拦住了不可逆的错，清单拦住了没想清楚的动手，收尾拦住了练完不收的尾巴，剩下的活，你才敢交给它自己跑。

护栏还有一个好处：出错的成本变小了。错发生在清单里，只是多问一句；错发生在动手后，可能是多发一条消息、多删一个文件。把错往前推，推到最便宜的地方去，这就是护栏真正的用处。

## 练一次：拿一次练习过一遍护栏

不用准备什么，十五分钟就够，拿第二篇练过的搜索当例子，全程只碰浏览器：

1. 动手前先过六问：在备用机或小号上练吗？这一步会对外产生效果吗？权限开齐了吗？快照是最新的吗？这一步不用交接单，失败了怎么停？六个问题都答得上来，再动手。
2. 在浏览器里查一个词，比如“胡巴”，跑快照确认结果页出来了。如果百度弹了验证码，停下来，在看得见的窗口里自己做完，再接着走——这一步就是护栏在起作用，不是练习失败了。
3. 查完对一遍：结果页里那句原话，是不是你要的那一句？不是就重查，别往下传。
4. 收尾：关掉浏览器会话，问自己三个问题：动手前我过了清单吗？动手时有没有一次动两步？卡住的时候我是停下来等人，还是硬往下走了？

走完这四步，安全护栏这一步就算练成了。下一篇文章，我们把脑子换成本地模型，看看电脑操作 Agent 能不能不依赖云端。
