# 搭一个个人电脑助手

前七篇走下来，东西都齐了：脑子有云端和本地两条路（第七篇），手有浏览器、桌面、手机三只（第二、三、四篇），手和手之间有一张交接单（第五篇），动手之前有一张安全检查清单（第六篇）。这一篇不教新东西，只做一件事：**把这七篇拼成一套每天能用的个人电脑助手。**

先说清楚，个人电脑助手不是一个新软件，也不是要你再装一个新工具。**它就是三条固定流程，加一张交接单，加一遍收尾。** 流程固定了，Agent 每天干的才是同一件事；流程不固定，每次都是现想现干，错的地方也每次都不一样。

先说一句贯穿全系列的话，收尾篇也一样：**只在备用机或小号上练。** 助手每天跑，错的机会也每天都有，更别拿主力机、主账号练手。

## 一、助手长什么样

一个能每天用的助手，只有三样东西：

- **固定流程：** 每天同一时间、同一顺序、同一验收标准。早上查天气和日程、记到今日清单、手机上看一眼——今天是这个顺序，明天还是这个顺序。顺序一变，交接单和验收标准全得重写。
- **一张交接单：** 第五篇那张 `.md` 文件，照样是手和手之间的关节。助手跑的每一步，都先写交接单再动手，跑完再对一遍。助手不是比你记得牢，是它每一步都有据可查。
- **一遍收尾：** 每天跑完，对结果、断开手机、关掉浏览器会话。收尾不是可有可无的结尾，是助手“今天下班了”的标志。不收尾的助手，一直处于随时能接着干的状态，那是最危险的状态。

这三样东西合起来，助手每天做的事就一句话：**按固定顺序查、记、看，中间每一步都对交接单，最后收尾关机。** 听起来没什么新鲜的——新鲜的本来也不在这里，新鲜的是它每天都这么跑，跑错了你能立刻知道错在哪一步。

## 二、先定三条固定流程

别一上来就想“让助手帮我办一切”。先定三条小流程，跑顺了再加。定流程的时候，每条只写三行：干什么、用什么手、做完怎么算对。

1. **早上简报：查天气和日程，记到今日清单。** 浏览器里查明天的天气和今天的日程，记到桌面上的今日清单里，手机上看一眼确认。验收标准是：清单上的每一行，都和浏览器里查到的原话一字不差。这是第二篇的查、第三篇的记、第四篇的看，连起来的第一条流程。
2. **查一句、记一句：白天随手记。** 白天想到一件事要办，先在浏览器里查清楚，写进交接单，再记到桌面上的清单里。只查、只记，不发、不提交、不对外产生效果。验收标准是：记下来的那句话，和交接单上的原话一样。这是第五篇那套“查→记→看”里最常用的一段。
3. **晚上收尾：对清单、断手机、关会话。** 对一遍今日清单和交接单：办了的划掉，没办的写到明天；手机断开连接、关掉 USB 调试；关掉浏览器会话。验收标准是：清单和交接单对得上，手机和浏览器都断开了。这是第六篇收尾四件事的每天版。

三条流程定下来，先别急着加第四条。**助手能每天用的前提，是这三条每天都跑得下来。** 跑一个星期，三条都稳了，再加一条；跑一个星期，有一条总卡住，先把那一条拆小，别急着加新的。

## 三、脑子用云端还是本地，怎么定

第七篇给了两条换脑子的路，到了搭助手这一步，就要定下来：你的助手，脑子放哪？

1. **练手和私事，放本地。** 早上简报、随手记这种错了能重来的活，本地脑子够用：私密、不花钱、断网也能跑。第七篇那句话还适用：先从 3B 练起，跑顺了再试 7B；7B 卡了就退回 3B，别硬上 14B。
2. **必须一次成的事，放云端。** 要对外发出去、要付款、要提交的东西，本来就该人来做；就算只是让 Agent 准备材料，也要用更稳的脑子。本地小模型十次可能只成六次，这种活不适合它。
3. **一台助手，脑子可以混着用。** 不用非此即彼：每天的固定流程走本地脑子，遇到重要事，换回云端脑子再跑一遍。换脑子的办法第七篇写过：改一行地址，指向本地接口或者云端接口，手不用重学。
4. **不管脑子放哪，接口别对外开。** Ollama 的 11434 和 LM Studio 的 1234 只监听本机，别改成对所有网卡监听，更别转发到公网。助手每天跑，接口对外开一天，就等于把一台能替你点电脑的机器挂在网上给人用。

定脑子的时候，问自己一句话就够了：**这条流程错了，我能重来吗？** 能重来就放本地，不能重来就放云端，或者人来做。

## 四、完整跑一遍：从早上到晚上

三条流程和脑子都定了，现在把一整天串起来跑一遍。跑的时候记住第六篇的规矩：一次只动一步，动完再看；卡住了停下来等人；范围变了重过一遍。

1. 早上，跑第一条流程：浏览器里查天气和日程，跑快照确认结果页出来了，把原话写进交接单；桌面上打开今日清单，照着交接单记下来，记完跑快照，确认一字不差；手机上打开清单看一眼，确认它和交接单上的一样。
2. 白天，跑第二条流程：想到一件事，先查清楚，写进交接单，再记到清单里。记完就停，不急着把后面的事也办了。清单是记事的，不是办事的。
3. 晚上，跑第三条流程：对一遍清单和交接单，办了的划掉，没办的写到明天；手机断开连接、关掉 USB 调试；关掉浏览器会话。收尾做完，问自己三个问题：今天的清单和交接单对得上吗？中间有没有哪一步是我凭猜测走的？哪一步最卡，明天要拆小吗？
4. 跑完这三条，助手今天就下班了。不要顺手再加一条“反正都跑起来了，顺便把那个也办了”。顺手加的活，没有交接单、没有验收标准，错了你也不知道错在哪一步。

这一天跑下来，你会发现助手真正省下的不是时间，是“每次从头想一遍怎么做”的力气。流程固定了，你只需要看交接单、看验收标准，剩下的就是同一套循环：看→动→再看。

## 五、安全提示：护栏还在，收尾篇也不例外

搭助手的时候，安全规矩一条都不能少，收尾篇把它们再收一遍：

1. **两条红线照样在。** 不可逆的事必须你点头；密码、验证码、密钥这些秘密信息绝不外发，也不进交接单。助手每天跑，红线每天都在。
2. **每过一道手，人确认一次。** 助手不是让你撒手不管，是让你只看关键处：交接单对不对、验收标准过了没。确认的成本是一句话的事，不确认的成本是一整天办错。
3. **练完就收，收尾就是下班。** 手机断开、浏览器会话关掉，交接单留在本地就行。不要让助手一直处于“随时能接着干”的状态。
4. **流程变了，重审一遍。** 想加一条新流程、想换一个脑子、想把练手的活拿到正式账号上做，都是范围变了。范围一变，动手前的六问就作废了，停下来重过一遍，再决定要不要继续。

护栏不是束缚，是让助手每天都敢跑的底气。没有护栏的助手，跑得越勤，错得越快。

## 练一次：跑一遍你的早上流程

不用准备什么，三十分钟就够，全程只碰浏览器、一个文本编辑器和手机备忘录：

1. 写下你的早上流程：查什么、记到哪里、手机上看什么。只写三行：干什么、用什么手、做完怎么算对。
2. 按第四节的第 1 步跑一遍：浏览器里查天气和今天的日程，写进交接单；桌面上记到今日清单，记完跑快照确认一字不差；手机上看一眼确认。
3. 跑完问自己三个问题：哪一步最顺？哪一步最卡？卡的那一步，是手的问题、脑子的问题，还是流程本身写得不清楚？
4. 收尾：对一遍清单和交接单，手机断开连接、关掉 USB 调试，关掉浏览器会话。把卡住的那一步记下来，明天只改那一步，别把整条流程推倒重来。

走完这四步，你的个人电脑助手就算搭起来了。它不大，只有三条流程、一张交接单、一遍收尾——但它是你的，每天跑，错了能查到哪一步，改了明天接着跑。

## 结尾：八篇到这里，就够了

第一篇认识了电脑操作 Agent，第二篇让它操作浏览器，第三篇让它操作桌面，第四篇让它操作手机，第五篇把三只手连起来，第六篇立了安全护栏，第七篇把脑子搬回本地，第八篇把这些拼成一套每天能用的助手。

八篇走完，你手里有的不是一个“会操作电脑的 AI”，而是一套练法：**看→动→再看，一次只动一步，每过一道手对一次交接单，动手之前先过护栏，练完就收尾。** 这套练法不只适用于今天这几只手，换一副新工具、换一个新模型，练法还是同一套。

往下走的路，你自己定：流程跑顺了，可以再加一条；本地脑子不够用了，可以换回云端；想练新工具了，照着这套练法从第一步重新走一遍。助手搭起来了，剩下的就是每天跑它、每天改它一点点。

谢谢你一路练到这里。下一台电脑、下一个助手，还是从“只在备用机或小号上练”开始。
