# 记忆和个性化：怎么让它越用越懂你，又不越界

上一篇讲的是浏览器和网站，这一篇讲的是比工具更贴身的一件事：记忆。

很多人第一次用 Muse 的时候，都会有同一个感觉：刚开始它什么都不了解你，问什么都要从头说；用了一段时间，它好像开始懂你了，不用每次都解释一遍。这个变化，靠的就是记忆和个性化。

先把一个概念说清楚：**记忆不是聊天记录。** 聊天记录是你说过的每一句话，越往下翻越长；记忆是从这些对话里留下来的、以后还会用到的东西，比如你的偏好、你的工作方式、你正在做的事。聊天记录是流水账，记忆是提炼出来的要点。

## 一、它会记住什么：值得留到下次的东西

值得它记住的，通常是这几类：

- **你是谁、怎么称呼你**：名字、你希望它怎么叫你、你的时区。
- **你的偏好**：比如你习惯用中文交流、你喜欢先看清单再动手、你不喜欢被反复打扰。
- **你的工作方式**：比如你写博客是先看草稿、点头了再推，或者你处理事情习惯先列出风险再决定。
- **你正在做的事**：比如你正在写一个十篇的系列，或者你有一个每周五要总结的目标。

这些东西有一个共同点：**下次还会用到。** 只用一次的细节，比如某天某篇文章里的某个数字，不值得专门记住，用的时候再查就行。

## 二、什么不该放进记忆：再方便也不行

有些东西，再方便也不应该让它记住：

- 密码、密钥、验证码、银行卡号、身份证号这些凭证和证件信息。
- 别人托付给你的私事，除非对方明确同意。
- 你自己都还没想清楚、只是随口一说的话。

记住一个简单的判断标准：**如果这条信息泄露了会让你难受，那就不要让它进记忆。** 记忆是为了省事，不是为了存秘密。需要凭证的时候，走专门的安全入口，而不是直接发在对话里。

## 三、怎么让它记住：直接说，不用写申请

让它记住一件事，不需要任何特殊格式，直接在对话里说就行：

> 以后写博客，每篇先给我看草稿，我点头了再推。

> 我习惯用中文，你以后直接用中文回我就行。

说完它就会记下来，下次遇到类似的事，它会按这个来。当然，你也可以随时问它：“你现在记着我什么？”如果它说的和你想的不一样，当场纠正就行。

## 四、记忆错了怎么办：纠正一次，胜过解释十次

记忆也会出错，而且出错的方式往往很安静：它不会告诉你“我记错了”，它只是按错的记忆去办事。所以当你发现它按一个过时的偏好做事时，不要每次都重新解释一遍，直接纠正那条记忆：

> 你记错了，我现在不是每周写两篇，是每周写一篇，改一下。

纠正一次，之后就不用再说了。反过来，如果你只是每次都绕开它、自己手动改，它永远不知道自己记错了，下次还会按错的来。

还有一个容易忽略的情况：**偏好变了，记忆没变。** 比如你以前喜欢早上推送，后来改成晚上了，如果你不说，它会一直按早上来。所以偏好一变，就顺手说一声，这比攒到出问题再纠正要省事得多。

## 五、怎么让它忘记：说出来就行，删了就不再用

想让它忘记某件事，同样直接说：

> 把我之前说的那条偏好删掉，我现在不用了。

删掉之后，它以后就不会再按那条来。但有一点要明白：**删掉记忆，不等于删掉聊天记录。** 对话记录还在，只是以后不会再把它当成你的偏好来用。如果你希望某段对话本身也被处理掉，要单独说清楚，而不是只说“忘记”。

## 六、记忆、对话、目标、提醒，四样别混了

这四样经常被混在一起，其实各管各的：

| 东西 | 管什么 |
| --- | --- |
| 记忆 | 长期留用的偏好和事实，下次还会用 |
| 对话记录 | 你说过的每一句话，是流水账 |
| 目标 | 一段时间内要达成的成果，有进度和完成标准 |
| 提醒 | 到时间做一件事，是时间点 |

举个例子：你说“以后博客先看草稿再推”，这是记忆；你正在写的十篇系列，这是目标；每周五总结一次进度，这是提醒；你们讨论这件事的完整过程，这是对话记录。四样配合起来，它才既记得你，又不会把一件事当成另一件事。

## 七、个性化有个度：懂你，但不替你做主

个性化用得好，是越用越顺手；用过头了，就会变成它替你做主。所以要守住一条线：

- **可以按记忆办事的**：格式、语言、提醒时间、做事顺序这些日常习惯。
- **必须停下来问你的**：花钱、对外发消息、删数据、改设置、公开任何东西。

记忆越丰富，这条线越重要。因为它越懂你，你越容易默认它都对，也就越容易在关键步骤上放松检查。记住：记忆是帮你省掉重复解释，不是帮你省掉最后点头。

## 练一次：今天就立三条记忆

不用多，先立三条，够用一阵子：

1. 一条称呼或语言偏好，比如用什么语言回你。
2. 一条工作方式，比如先看草稿再推，还是直接动手。
3. 一条边界，比如什么事必须先问你。

立完之后，下次它按这三条办事的时候，你就知道记忆已经开始起作用了。如果它按错了，纠正一次就行。
